Go 1.12

Part II · commits first contained in tag go1.12 ^go1.11 (tagged 2019-02-25) · 659 in-scope commits

Mark termination simplified, page reclaimer, more aggressive scavenger. Stack objects. ABI0/ABIInternal symbol split. Binary export removed; -lang. AIX port. MADV_FREE. macOS syscall via libSystem.

Each area lists the stage every thread reached in this release (with what was left open afterwards), then changes that are not part of a thread. Thread names link to the full thread on its topic page.

Memory management

From Memory management: GC and allocator (Go 1.0–1.17)

Mark termination simplification (mark 2, gchelper, gctrace=2 removed), page reclaimer, treap-only span tracking, aggressive scavenger with fixes.

  • Concurrent sweep and proportional sweep — Done: sweepone simplified and gosweepone removed (06afc8b152, f3bb4cbfd5), span mark bit (ba1698e963), arena slice and in-use page bitmap (e500ffd88c, 69e666e4f7), efficient page reclaimer (5333550bdc), large-allocation sampling fix (dc889025c7). Left open: nothing noted.
  • Decentralized GC state machine and mark termination simplification — Done: mark-termination cleanup listed above (9c634ea889, a2a2901b25, 9108ae7751, d398dbdfc3, 918ed88e47, 1678b2c580, e25ef35254, ecc365960b, edc2d17086, 198440cc3d, 457c8f4fe9, 550dfc8ae1, 873bd47dfb, 0906d648aa, 578667f4b5 preemptible mark termination goroutine); gList types for G queues (3578918b66, d02169d380, 083938df14). Left open: “P has cached GC work” cause not found, only worked around (95a6f112c6).
  • Stack scanning: conservative, precise by frames, stack barriers, hybrid barrier, async safe points — Done: gcrescanstacks removed (198440cc3d). Left open: nothing noted.
  • Hybrid write barrier and buffered write barrier — Done: barrier buffer flush creates GC work (9c634ea889), poisoning (fe2feb978e), growslice bulk barrier (96dcc4457b, 4363c98f62). Left open: nothing noted.
  • Allocating from mark bits: allocBits, freeindex and ctz — Done: span mark bit set whenever any object on the span is marked (ba1698e963). Left open: gcmarknewobject path missed it, fixed in 1.15 (886caba73c1.15).
  • Size classes, tiny allocator and mcache/mcentral — Done: mcache refill simplified (2d23ece135, 01e6cfc2a0), unneeded span tracking in mcentral dropped (70d7e96c78), newarray uses multiplication with overflow check (1e50dd02a9). Left open: nothing noted.
  • Span lifecycle in mheap: free lists, treaps, first-fit and the page reclaimer — Done: treap-only heap, separated scavenged spans, iterator, coalescing refactor (07e738ec32, b00a6d8bfe, b46bf0240c, e508a5f072, 3651476075, 79ac638e41, 2f99e889f0, 6e9f664b9a, 689fae2d78, 011b8eb6bb). Left open: best-fit by size led to fragmentation; first-fit adopted in 1.13.
  • Scavenger: returning memory to the OS — Done: scavenged/unscavenged separation and credit (b46bf0240c, e508a5f072, c803ffc67d, 06be7cbf3c, 064842450b, 6e9f664b9a, 8e093e7a1c, faf187fb8e). Left open: scavenging still inline with allocation.
  • Heap address space: contiguous arena to sparse arenas — Done: arenas slice (e500ffd88c), race-mode MAP_FIXED (7ef718f16f, from Dec 2018). Left open: nothing noted.
  • Mark work distribution: parfor, work buffers, gcWork and root jobs — Done: work-flush debugging (9098d1d854, 438b9544a0, bae1e70ac4, 8e6396115e). Left open: nothing noted.

Other changes

  • Misc internal — treap nodes not zeroed twice (011b8eb6bb), table of arena sizes (4c1c839a3d), sysUsed fixes (213845f7b9, db82a1bc12), TestArenaCollision (6fcab648af).
