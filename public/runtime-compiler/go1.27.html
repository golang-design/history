Go 1.27

Part II · master 83c44ec032..6c87434d24 · 861 in-scope commits

Generic methods. Size-specialized malloc on. Goroutine-leak profile by default. asynctimerchan and gotypesalias removed. mapsplitgroup experiment. Known-bits and LICM passes. Switch lookup tables. NEON, wasm and portable SIMD. Promoted fields as composite-literal keys.

Each area lists the stage every thread reached in this release (with what was left open afterwards), then changes that are not part of a thread. Thread names link to the full thread on its topic page.

Memory management

From Runtime: memory allocator and garbage collector (Go 1.18–1.28)

  • Green Tea: span-based marking with vector scan kernels — Done: kernel hardening: symbol names (d8d2b90a46), retpoline-safe assembly (8572b1cfea), requiring POPCNT for GOAMD64=v1 (45929774c3), and requiring AVX512DQ for KMOVB (661aadb7c4). Left open: nothing noted.
  • Heap bitmap rewrite and allocation headers — Done: the small all-pointer-array fast path computed scan size as only the first pointer; fixed (40a10063e8). Left open: nothing noted.
  • mallocgc decomposition and size-specialized malloc — Done: turned off at cycle start for “regressions in overall icache footprint at scale” (4af8ad24ee); the go1.26.0 tag shipped with it off via a release-branch cherry-pick. Then: tiny functions consolidated (9936a78b78); the fast path split (75560e67c9, 15f44ffcc3); benchmarks (15129eb73b, 24e654197a); classes >128 B and then >class 7 dropped (55089b9e27, 694604e524); dead race/valgrind branches removed (0a151acad8, bfbbe9667e); refactors (722ee60825, 15fd4ff942, c410b4944e, fe4da8e5c5); generator fixes (9301a3eab2, b23aea0c94, 2378242315); acquirem across the fast path (63b51fc270). Routing heap-bits-in-span through the slow path was tried and reverted as slower (dd1da37fa4, 01d183b000). Re-enabled by default (2a93576965). Left open: “We may want to test moving the boundary even lower” (55089b9e27). freegc for pointerful objects is disabled under specialization (TODO in freegc at HEAD).
  • Allocation publication, zeroing and preemptibility — Done: a preemptible memclrNoHeapPointersPreemptible for large pointer-free clear() and allocations, chunked at 256 KB, landed (50126a8e44). A stack-pointer fix followed (cd2fa3b48d). Both were reverted because preemptible clears “expose existing unsafe use of notInHeapSlice” (16018b05ae, 5f5f4ccdb3). Left open: #69327 (non-preemptible multi-MB clears blocking STW) remains open pending the notInHeapSlice fix.
  • Stack and register root scanning — Done: extended (vector) register state of async-preempted goroutines is scanned conservatively, so vectorized moves may carry pointers (683aa8893a). On arm64 the 16-byte frame holding R30 from pushCall is scanned (a129840779). Left open: nothing noted.
  • Address-space layout, tagged pointers and the mem.go layer — Done: sysUnreserve and LSAN coverage (40ec033c33), sysFree docs (4ce2612f21). Left open: “I am not completely confident that we always pass the full region to sysFree” (40ec033c33).
  • Linear-memory heaps (Wasm and sbrk platforms) — Done: nil pointer handling in sysFreeOS on sbrk (649897800b). Left open: nothing noted.

Other changes

  • Goroutine leak profile user-visible — experiment enabled by default (253aa2a12a) then deleted (afcf04cb64); the main goroutine blocked on select{} is still analysed as leaked for precision but reported as waiting (d81ba6c35d).

  • Contended runtime-lock profiling (mutex profile for runtime-internal locks) — Done: m.locks bit-split so lock/unlock count in steps of 16 while acquirem stays +1, so a mutex-count of zero is detectable when acquirem/releasem is interleaved (b99b8feaae; fixes dropped samples in TestRuntimeLockMetricsAndProfile); gscan vs profInsert rank deconflicted (29c1c946aa). Left open: nothing noted.
  • testing/synctest bubbles — Done: concurrent race-context use in synctest timers avoided (784ea961a4); crypto/fips uses unbubbled monotonic clock (a81b20a431). Left open: nothing noted.
  • Asynchronous preemption: extended register state — Done: conservative scan of extended register state (683aa8893a); loong64 fcsr0 (e76c910108). Left open: nothing noted.
  • sync package API evolution — Done: linkname replaced with import (97259c5d6b); Cond.Broadcast lock guidance (1225feb0da). Left open: nothing noted.
  • sync/atomic and runtime atomics — Done: PPC64 Add/And/Or SQCST (f4d1304904); linknames simplified (0dcd7ab1b9). Left open: nothing noted.
  • Goroutine lifecycle and identity — Done: goroutineleakprofile enabled by default then experiment dropped (253aa2a12a, 16449179ec); secret state inheritance (e26a373785). Left open: nothing noted.
  • Fast random numbers for the scheduler — Done: 32-bit cheaprand via 64-bit multiply; cheaprand64 as 64-bit wyrand (27fcec4d8f). Left open: nothing noted.

Other changes

  • Misc internal — signal stack clearing when parking Ms (62a1da372a); reflect.typelinks returns types (87fae3622d); panic record cleanup (e93b26688c); AIX GCData (bd1b41eb81); tracebacklabels default (3694f33692); invalid GODEBUG messages (0ed83956d3); Int16 atomic non-goal documented (0af7dbf1e6).

Data structures and type metadata

From Runtime: maps, built-in data structures, hashing, randomness and type metadata (Go 1.18–1.28)

  • Swiss-table maps (GOEXPERIMENT=swissmap → only implementation) — Done: user-visible GOEXPERIMENT=mapsplitgroup added, off by default: groups become ctrl; keys [8]K; elems [8]V so map[K]struct{} no longer pays a padded elem per slot (5560073398; trade-off stated: better key cache behaviour, elem no longer at a fixed offset from its key). Lowering mapaccess1* to mapaccess2* at walk time to share one implementation (62d08234b7); undone in the same cycle because OINDEXMAP is used in expression context and late replacement generated invalid code (2a4fbc3f24), leaving mapaccess1 as a wrapper around mapaccess2. Devirtualised hashing in specialised maps (252a8adbc0), pointer-key fast variants were missing pruneTombstones (03dc8c482f, 3cf84263ec), ctrlGroupMatchH2 on arm64 rewritten to avoid cross-byte borrow false positives (f133609b75), small full maps only grow when inserting a new key (8042aaf03c), correct const for indirect elem flag (51a8f213cd). Left open: mapsplitgroup not default; hashing not yet inlined into map functions (252a8adbc0 says “opens opportunity for further improvement by inlining hashing calls in the future”).
  • Map hashing and hash functions (memhash, aeshash, fallback hash) — Done: all assembly hash functions (386/amd64/arm64, aes and noaes) moved from runtime to internal/runtime/maps as “ground work” for rewriting with SIMD intrinsics and inlining into map functions (8594bf4621, 34 files); MemHash{32,64} rewritten with simd/archsimd intrinsics under GOEXPERIMENT=simd (2403e594a5, -8.67% on one geomean, others within noise; MapAccessZero/Empty swings attributed to basic-block alignment); keys passed by value to MemHash{32,64}/StrHash to avoid address-taken keys and reloads, and strHashAES folded into memHashAES (05f75fb9e8). Left open: hash inlining into map ops still future work.
  • Compiler-generated equality/hash functions and type descriptor emission (reflectdata) — Done: signature-based equality (30dff416e4, 6eec9bcdb2), signature-based hash (0da8979210), type descriptor alignment set to 8 (a430bc1bd7: cmd/go -88K), MaxPtrmaskBytes back to 16 since GC programs are gone (a409055b7c; tailscaled: types needing runtime-computed masks 6→49, ~100 bytes saved), descriptor size constants moved to internal/abi (d440b8b485), zero-size array element crash fix (cf0c42c2ca), linker handling of runtime.types leading offset based on size, not GOOS (20bc194972), AIX user-created GCData adjustments (bd1b41eb81). Left open: “Maybe a TODO for the future”: only generated comparison functions use signatures, not the code generated for == itself (30dff416e4).
  • internal/abi type layout unification and type metadata (rtype → abi.Type) — Done: type descriptor sizes in internal/abi (d440b8b485), MaxPtrmaskBytes=16 (a409055b7c), reflect.typelinks returns types, not offsets, via new runtime accessor; old function kept for linknamers (87fae3622d). Left open: nothing noted.
  • reflect implementation: performance, allocation and escape behaviour — Done: conversions between slices of named byte/rune and string (a0796d8af6), Select []runtimeSelect kept on stack (094aacdb04: B/op -12.9%), &zeroVal[0] for zero-sized payloads (60dc96479a), Value.Methods/Fields examples and nil-interface panic (31768104cb, 891f4a8711), MapMaxElemBytes correction (f7d886207f), reflectlite cleanups (b04e7f31c8, d8034799e0). Left open: nothing noted.
  • memmove / memclr / memequal / internal/bytealg assembly optimisation — Done: android/arm64 fixes to never read outside 16-byte regions (f5479628d3, 1a0e1fb616), Rabin-Karp helpers unexported (f1e016bb3a). Left open: nothing noted.
  • Slice growth, string building and allocation-free bytes/strings helpers — Done: moveSliceNoCap rounds size down to a whole multiple of element size (1a15699a43). Left open: nothing noted.

Other changes

  • Runtime print helpers hardened internal — printquoted keeps invalid UTF-8 bytes and fixes decoderune use, printfloat/printcomplex buffer sizes, printint/printuint avoid append (Go 1.26/1.27: cdf8951060, e1e73b316c, cc1241f353, e2c6a2024c1.26).
