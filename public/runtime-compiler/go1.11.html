Go 1.11

Part II · commits first contained in tag go1.11 ^go1.10 (tagged 2018-08-24) · 991 in-scope commits

Sparse heap arenas and no heap-size limit. Indexed export format. Concurrent compilation of all functions. Safepoints almost everywhere, with register liveness maps. Prove pass reworked. WebAssembly port. Darwin syscalls through libc. Trace user annotations. DWARF compression. internal/bytealg. Debugger call injection.

Each area lists the stage every thread reached in this release (with what was left open afterwards), then changes that are not part of a thread. Thread names link to the full thread on its topic page.

Middle end and SSA optimizer

From Middle end and SSA optimizer (Go 1.10–1.17)

The prove pass was reworked (unsatisfiability, poset, loop BCE folded in, loopbce deleted), range loops stopped producing past-the-end pointers, location lists were redesigned, is_stmt statement boundaries and stack maps at nearly every instruction landed, and mid-stack inlining prerequisites (variadics, panic, thresholds) arrived; arm64 got CondSelect (threads: Prove, Statement boundaries, DWARF, Inlining, CFG passes, Range loops).

  • Prove pass: unsatisfiability, partial-order facts, loop bounds-check elimination — Done: unsatisfiability design (669db2cef5), simpler limit logic and unsigned limits derived from signed (2e9cf5f66e, 941fc129e2), fence-post implications (6436270dad), fail fast on unsat and short-circuit self-facts (385d936fb2, d54902ece9), relations between constants (8d8f620f68), len/cap relations in factsTable.update (4816eface1), OFORUNTIL inductive facts (b812eec928, needed by the new range lowering), loop BCE inside prove and removal of loopbce (7ec25d0acf, f49369b67c), full OpIsInBounds/OpIsSliceInBounds support (ac43de3ae5), unsigned relations while branching (29162ec9a7), poset transitive closure (5c40210987), negative-increment loops (6d379add0f), len(s)-delta (e0d37a33ab), shift simplification (9eb4590ad2). Left open: poset only used for relations, not limits; fence-post for the unsigned domain was wrong (fixed in 1.12).
  • Escape analysis: the esc.go fixes, the escape.go rewrite, and the move to package escape — Done: go:uintptrescapes for unnamed parameters (beeab6ac02), loop depth to field (5a91c83ce8), element type for OIND of slices (3042463d61), explanation of escape reasons (a12c1f26e4, 360c19157a), anonymous receivers non-escaping (88466e93a4). Left open: nothing noted.
  • Inlining: budget, mid-stack inlining, closures, and what became inlinable — Done: variadic functions (09d4455f45), parameter refactor + panic inlinable (87a18c6109), larger-function threshold (5fc70b6fac), constant if (d7cd61ceaa), go:norace (c6e455bb11), struct == cost (b638760dad).   • DWARF location lists from SSA — Done: reimplementation (2075a9323d), memory use (39eea62340), dead locals in inline DWARF (1ba26a33ce). Left open: macOS base-address entries (commit says “TBD”).
