Go 1.22

Part II · master 21ff9be0eb..1653833811 · 883 in-scope commits

Per-iteration loop variables. Range over int. Range-over-func as an experiment with coroutines. Allocation headers. New execution tracer by default. ChaCha8 randomness. Type-switch and assertion caches. SCCP. loong64 register ABI.

Each area lists the stage every thread reached in this release (with what was left open afterwards), then changes that are not part of a thread. Thread names link to the full thread on its topic page.

Memory management

From Runtime: memory allocator and garbage collector (Go 1.18–1.28)

  • Soft memory limit and GC CPU limiter — Done: gcPaceScavenger’s memory-limit goal was corrected to (100−reduceExtraPercent)/100 × limit (729f214e3a). Left open: nothing noted.
  • Heap bitmap rewrite and allocation headers — Done: user-visible preparation (7a606fef66, cdf1362179, 25867485a7), the allocheaders implementation (38ac7c41aa), and default enablement (e3585c6757). Benchmarks with footers: GoBuild −3–4%, tile38 −1.9% (1e250a2199). Headers were restored after a persistent dashboard regression (0ef169abb1). Follow-ups: typePointersOfType fast path for bulkBarrierPreWrite, removing a p90 regression (d6ef98b8fa); memory-profile accounting using the full elemsize (f67b2d8f0b, c418da34cd); arena largeType clearing (052d402985); unrolled-bitmap flag (ee4b61a32e) and freeing leak (0f3876f8c1); smaller mspan.freeindex/nelems fields (340a4f55c4); test fixes (17eb0a2bac, b71d43296f1.21). Left open: objects may lose incidental 16-byte alignment; “A follow-up change will add a GODEBUG flag that ensures 16 byte alignment” (0ef169abb1). No such GODEBUG exists in internal/godebugs at HEAD.
  • Scavenger redesign — Done: corrected memory-limit goal (729f214e3a); sysGrow min-index bug that remapped and zeroed live index data (c95fe91d07). Left open: nothing noted.
  • Transparent huge page management — Done: user-visible MADV_COLLAPSE instead of MADV_HUGEPAGE (9f9bb26880), then “don’t eagerly collapse hugepages … Disable it until further notice” (595deec3dd), with dead code deleted (765dfb00b2). Metadata huge-page calls moved to the system stack to avoid a self-deadlock on stack growth (5f08b44799). GODEBUG=disablethp was added, because 1.21.1+ stopped working around the kernel’s khugepaged behavior (c915215af6). Left open: the runtime no longer stops khugepaged from re-backing returned memory: “basically unavoidable without a new madvise flag” (9f9bb26880).
  • Object pinning (runtime.Pinner) — Done: user-visible Pin silently accepts non-Go pointers (bfa8a8586f), with reworded docs (451e4727ec). Left open: nothing noted.
  • Memory arenas experiment — Done: adapted to allocation headers (cdf1362179); big-endian heap-bit byte order (f7c5cbb820); clearing mspan.largeType without a write barrier (052d402985); test (90a73ec1f2). Left open: “Much of this can be avoided … if the compiler were to write out the pointer/scalar bits as an array of uintptr” (f7c5cbb820).
  • Mark worker scheduling and GC work queues — Done: all mark workers yield to forEachP (needed by the new tracer, 25895d1c99); per-worker-kind gcDrain wrappers so profiles show which kind is running (081d27a2e5). Left open: nothing noted.
  • Sweeper termination and pacing — Done: GODEBUG=gcstoptheworld=2 now flushes mcaches in gcSweep, _ConcurrentSweep removed (4f4c23512e); write-only fields deleted (7241fee9b0). Left open: nothing noted.

Other changes

  • writeBarrier.needed folded into enabled internal — (72da49caee).
  • mheap.arenas false sharing internal — padding gave +17% on MinIO with GOGC=1000 on 112 cores (b45b00162b).
  • sync.OnceFunc/OnceValue(s) drop the function after first call user-visible — stops it keeping its captured allocations alive (4f55a5af5e).
  • work.pauseStart removed internal — (7a6ddbb425).
  • Tracer API as a lock internal — GC/sweep tracing calls rewritten to the traceAcquire/traceRelease pattern (f119abb65d), diag area.

Scheduler and concurrency

From Runtime: scheduler, timers, channels, locks and synchronization (Go 1.18–1.28)

  • Contended runtime-lock profiling (mutex profile for runtime-internal locks) — Done: user-visible mutex profile counts every blocked goroutine (1c00354013); runtime-internal lock contention profiled (0b31a46f1f, reverted 468bc94188, relanded 450ecbe905); GODEBUG=profileruntimelocks renamed runtimecontentionstacks and sentinel _LostContendedRuntimeLock (98fd8f5768). Left open: attributes the waiter’s own wait time, not the delay the critical section caused; futex locks “too late in the cycle” to fix.
  • Scheduler core: spinning Ms, work conservation, stealing, STW interaction — Done: gosched calls wakep after pushing onto the global runq: without it, a spinning M that had just checked the global runq could park while the yielder’s G was stranded (loss of work conservation, with sysmon’s 10ms preemption the only backstop) (ad943066f6); global runq checked in the delicate dance (dd5db4df56); forEachP wrapper moves caller to _Gwaiting like stopTheWorld to avoid deadlocks with GC stack scanning (ff7cf2d4cd); m.locks-related and wirep throws moved to systemstack (37aed23f51). Left open: sysmon still preempts regardless of idle Ps (#60693 referenced).
  • Coroutines (iter.Pull runtime support) — Done: iter, runtime: add coroutine support, exported under GOEXPERIMENT=rangefunc (a9c9cc07ac). Left open: interaction with thread-locked goroutines.
  • sync package API evolution — Done: Once-wrapped functions are not kept alive after running (4f55a5af5e); Pool panics rather than throws on nil receiver (be0e0b06ac); Map.Range no longer always escapes (7015ed891c); Once uses atomic.Uint32 (be3d5fb6e6). Left open: nothing noted.
  • Runtime lock ranking — Done: wakeableSleep edges (5a6f1b35d4, 23c0d30244); rwmutex (9b4b3e5acc, dcbe772469). Left open: nothing noted.
  • Netpoller — Done: netpollWaiters adjusted after goroutines ready and in netpollunblock (f51c55bfc3, eaa8419a72). Left open: nothing noted.

Other changes

  • rangefunc runtime preparation internal — _defer room (390763aed8), deferreturn without unwinder (9869699c44), pruned _defer fields (0c2abb3233).
  • g0/crash stack and cgo internal — callback stack bounds update reverted (a46b1ad357, ea8c05508b), stackguard1 on extra M (9af74e711a, c0c4a59816), dropm clears bounds (1af424c196), crash stack disabled on Windows (dc094f9c96), sched.lock over traceThreadDestroy (cea35baf12), pcvalue cache to M reverted (d367ec6a0e, 26e0660811).
  • g0/crash stack internal — larger g0 in non-cgo (c6d550a668), crash stack via stackalloc (e293c4b509), reverted callback bounds/stackguard1/pcvalue variants (4f9fe6d509, 2b462646ed, 4a8373c553).
  • Misc internal — wakeableSleep send-on-closed fix (3073f3f941); debugcall locks OS thread (d9a4b24a17); AIX noteclear (a762ea17ec); copyChecker doc (18b2c45b0a); atomic integer sweep (4988a65f2a); wine hacks removed (4beb33018b); arm64 saved fp zero (94d36fbc4a); memhash_varlen devirtualisation (3fd5c357a3); stack bound docs (a7c3de7052).
