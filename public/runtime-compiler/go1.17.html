Go 1.17

Part II · commits first contained in tag go1.17 ^go1.16 (tagged 2021-08-16) · 1482 in-scope commits

Register-based ABI on amd64. The dev.regabi split of the compiler into packages. dev.typeparams: types2, -G, irgen and first stenciling, all off by default. Pacer extracted into gcControllerState. unsafe.Add/unsafe.Slice. Slice-to-array-pointer conversion. windows/arm64. go/defer wrapped into closures.

Each area lists the stage every thread reached in this release (with what was left open afterwards), then changes that are not part of a thread. Thread names link to the full thread on its topic page.

Memory management

From Memory management: GC and allocator (Go 1.0–1.17)

Pacer extracted into mgcpacer.go as gcControllerState, sweep completion unified, incremental arena preparation, stack-object GC data only.

  • Concurrent sweep and proportional sweep — Done: sweep completion unified: runtime.GC now blocks on all sweep paths (a25a77aed2, 1b736b3c19). Left open: nothing noted.
  • GC pacer: trigger controller, assists and background utilisation — Done: pacer extracted into mgcpacer.go with gcControllerState methods (f5f7647107, f2d5bd1ad3, 728e3dc6f9, 2d4ba2601b, 9bce7b70fd, e7ab1a5ba8, 7ec7a3cf33, e9cc31e736), minimum scavenge fraction constant fixed (14ade57ab8). Left open: the trigger-ratio model itself; this refactor is the preparation for the 1.18 pacer redesign.
  • Stack scanning: conservative, precise by frames, stack barriers, hybrid barrier, async safe points — Done: stack-object metadata emits only GC data instead of the full type descriptor, avoiding keeping the descriptor and everything it references alive (02ab8d1a1d); GC testing helpers for moving stacks (4e1bf8ed38, 97b3ce430b, 41e8a9f1cf). Left open: nothing noted.
  • Precise heap scanning: type information, the heap bitmap and GC programs — Done: scanobject hbits advance folded into the loop (72483de87a). Left open: nothing noted.
  • Size classes, tiny allocator and mcache/mcentral — Done: simplified divmagic (4662029264), alignment doc fix (a8a85281ca), tiny allocs top-aligned in race mode (2c05ba4ae0), large clears broken into chunks so preemption can occur (0bbfc5c31e). Left open: “huge” clears remain non-preemptible while a single clear runs (explicit in the commit message: zeroed by chunks “so that preemption can occur”).
  • The bitmap page allocator — Done: arenas prepared incrementally via sysMap in grow for strict-overcommit systems (bd6aeca968), pageAlloc handles sysAlloc failures (0e8a72b62e). Left open: nothing noted.
  • Scavenger: returning memory to the OS — Done: scavengePercent min fraction constant fix (14ade57ab8). Left open: the 1.18 redesign (controller-paced) follows.
  • Heap address space: contiguous arena to sparse arenas — Done: incremental arena preparation, 4 MiB arenas on iOS (bd6aeca968, e03cca6407). Left open: nothing noted.
  • Finalizers and span specials — Done: register-ABI finalizers (f009b5b226), abstracted specials list iteration (1ef114d12c). Left open: nothing noted.
  • Mark work distribution: parfor, work buffers, gcWork and root jobs — Done: root bases computed in gcMarkRootPrepare (82e4a6310b), nFlushCacheRoots removed (94817890c2). Left open: nothing noted.
  • Memory statistics and accounting — Done: internal pacing stats moved into gcController (f2d5bd1ad3). Left open: nothing noted.
  • Allocation-site profiling and GC debugging modes — Done: clobberdead check in GC (0ccdcb2102), GC testing helpers (4e1bf8ed38). Left open: nothing noted.

Other changes

  • Misc internal — regabi finalizers, clobberdead, KeepAlive doc warning that it is not an unsafe.Pointer workaround (fd45e267c2), formatting (e224787fef, d434c2338b, 8a4b7294af).
  • Alignment info in sizeclasses comments internal — Added alignment information to the sizeclasses.go comments. (735647d92e)

  • The G-M-P scheduler: from global-lock M:N to per-P run queues, spinning Ms and work stealing — Done: findrunnable refactoring in preparation for the 1.18 spinning rework: work stealing in its own function 60ab197bc2, spinning coordination documented 13368ab56a, timer and spinning rechecks reordered f6e7fe2711, dbade774c3, 4d56576ec0, tryWakeP removed 800fb11efb; runqdrain for GC workers fbb600b283/3b304ce7fe; gFree lists moved in batches between P and global 1f7a01459b; pidleget/pidleput under sched.lock 2520e72d3b; exitsyscall0 race e0d029f758; p struct padding 55d7dcc3cd.   • Preemption: cooperative stack-check preemption (1.2) to signal-based asynchronous preemption (1.14) — Done: R15 saved before checking AVX state c49c7a675a; SPWRITE functions in traceback accounted for (not async-preempted since assembly functions never are) 03886707f9; preemption disabled in addtimer aa26687e45.
  • Network poller: from the netFD select loop to the runtime-integrated epoll/kqueue/IOCP poller — Done: netpollopen error handled in poll_runtime_pollOpen ebb92dfed9, netpollclose documented 437d229e2a, pollDesc lock partial edges e8e425cb23, 0e0a872a761.16.
  • Timers: timerproc goroutine → per-bucket heaps → timers on Ps — Done: findrunnable timer computation moved f6e7fe2711; adjustTimers counter removed bfbb288574, 798ec73519; addtimer without preemption aa26687e45; time.now in assembly on linux/amd64 d09947522d with walltime removed 42953bc9f5, b15372f39b, c96fec9036.
  • sync.Pool — Done: random victim selection when stealing d5d24dbe41.
  • sync.Map, atomic.Value and sync/atomic — Done: user-visible Value.Swap and CompareAndSwap 2422c5eae5.
  • Runtime lock ranking (static lock order checking) — Done: partial order self-check c41bf9ee81; pollDesc edges e8e425cb23; forceGC to traceStackTab edge d75fbac54d.
  • Goroutine and M lifecycle: caches, ids, LockOSThread, Goexit, cgo extra Ms, deadlock detection — Done: zero-sized frame check moved to newproc1 352d329c44; ncgocall made a global counter d01bc571f7.
  • Stop-the-world, safe points and GC–scheduler interaction — Done: runqdrain for GC mark workers fbb600b283/3b304ce7fe.
