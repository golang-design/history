Go 1.18

Part II · master 46fd547d89..936c7fbc1c · 1569 in-scope commits

Generics land: types2 plus GC-shape stenciling on the old typechecker. The register ABI spreads to arm64 and ppc64. The pacer is redesigned to count stacks and globals. GOAMD64 levels appear. Defers become argless closures. pclntab starts losing relocations.

Each area lists the stage every thread reached in this release (with what was left open afterwards), then changes that are not part of a thread. Thread names link to the full thread on its topic page.

Memory management

From Runtime: memory allocator and garbage collector (Go 1.18–1.28)

  • GC pacer redesign — Done: user-visible Pacer state was untangled from global state so it could be unit-tested: atomic gcPercent (6508fdad9d), scavenger pacing (f99e40aac0), sweeper pacing (413672fc84), startCycle/endCycle/heapLive methods (4a5d78ff8b, 8e112a7c2a, 5ec2427357), atomic types (75b73d68b3, 2f71c86370, 09e8de70c2), and a simulation test framework driven by the real pacer (994049a9ad, b5a5b7bfb1). The redesign landed behind GOEXPERIMENT=pacerredesign. Its message says “on by default”, but the commit does not touch internal/buildcfg (a108b280bc); a separate commit turned it on (961aab26bf). The minimum heap was cut to 512 KiB on the basis of ~200 KiB of runtime globals. That was pulled back into its own off-by-default heapminimum512kib experiment after ~1% build slowdowns and “up to 8x” more GCs for <4 MiB heaps (c5c1955077). Fixes: hard-goal computation (156abe5122); the PI controller made robust to overflow/NaN (e4a173adf6); exact float arithmetic for GOGC=25 (8f374aa27f). Left open: the hard-goal case “is impossible [to test] in the idealized model … leave a TODO” (156abe5122). The heap-minimum question was deferred to “next cycle” (c5c1955077). biogo-igor regressed because the write barrier stays on longer (a108b280bc).
  • Scavenger redesign — Done: PI controller (e48e4b4cbb), atomic scavengeGoal (fc5e8cd6c9), lock-free scavenging (4f543b59c5, 6d1fffac63), the 1% total-CPU target (6f32d2050d), a released-bytes accumulation fix (f986191325), and a conservative fallback when the controller overflows (e4a173adf6). Left open: the scavenger “is not really in a testable state” (e4a173adf6).
  • Allocation publication, zeroing and preemptibility — Done: zeroing unified in mallocgc. Small-object spans from mheap are never zeroed eagerly, and the flag became delayZeroing, used only for pointer-free large objects (d8fc7f785e). Left open: nothing noted.
  • Sweeper termination and pacing — Done: atomic sweep termination (3aecb3a8f7); GCSweepStart trace event fix (903f313d8b). Left open: nothing noted.
  • Stack and register root scanning — Done: markroot read allgs concurrently with allgadd and could see nil on weak memory; gcMarkRootPrepare now snapshots the slice header during STW (08ecdf7c2e). Also clobberdead pointer crash support on ARM64 (55b4310acd). Left open: nothing noted.
  • Address-space layout, tagged pointers and the mem.go layer — Done: ios/arm64 moved to 40 address bits with the 64-bit incremental page allocator (c27a3592ae); mmap failure printed (bb7fb8a5fa). Left open: the exception for iOS <14 stays “Once iOS <14 is deprecated” (c27a3592ae).

Other changes

  • mheap sweep/reclaim counters to typed atomics internal — pagesInUse, pagesSwept, pagesSweptBasis, reclaimIndex, reclaimCredit converted with rf scripts (d419a80bc7, e90492882a, 1dff8f0a05, a91e976fd2, 016d5eea11).
  • fixalloc hardening internal — object size bounded to [sizeof(mlink), _FixAllocChunk] (90ed541149); chunk tail waste eliminated (4591f49938). getMCache takes an mp (84ba117fd7).
  • reflect.Value.Elem on notinheap pointers user-visible — panics instead of creating a GC-visible bad pointer (8331f25e96).
  • faketime vs GC internal — the scavenger runs one loop under faketime, and the write path has no write barriers (0440fb8334). gcParkAssist dropped nowritebarrier (aeb4fbabc0).
  • GC background goroutines use real closures internal — once the compiler allowed escaping closures in the runtime (dev.typeparams defer/go wrapping), the argumentless-closure workaround for go’d GC, sweep and scavenge goroutines was undone (3298c749ac).
