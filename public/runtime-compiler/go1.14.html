Go 1.14

Part II · commits first contained in tag go1.14 ^go1.13 (tagged 2020-02-25) · 826 in-scope commits

Asynchronous (signal-based) preemption. Timers on Ps. Open-coded defers. Bitmap page allocator. riscv64 port. First pieces of the new object file format. Overlapping interfaces. checkptr.

Each area lists the stage every thread reached in this release (with what was left open afterwards), then changes that are not part of a thread. Thread names link to the full thread on its topic page.

Memory management

From Memory management: GC and allocator (Go 1.0–1.17)

New bitmap page allocator, self-paced scavenger, async-preemption support for GC (conservative scanning), trigger ratio floor.

  • Decentralized GC state machine and mark termination simplification — Done: STW GC releases worldsema before Gosched (05511a5c0a); g.gcscanvalid removed (8c5861576a). Left open: nothing noted.
  • GC pacer: trigger controller, assists and background utilisation — Done: trigger-ratio floor 0.6 (74af7fc603), hard goal fallback (aae0b5b0b2). Left open: the trigger ratio design needed rethinking (1.18).
  • Stack scanning: conservative, precise by frames, stack barriers, hybrid barrier, async safe points — Done: gcscanvalid removed (8c5861576a); shrink only at synchronous safe points (6058603471); conservative scan at async safe points (d16ec13756); markroot overflow fixed (66e562cc52). Left open: async preemption’s own injection is in the scheduler area.
  • The bitmap page allocator — Done: page allocator (14849f0fa5, 39e8cb0faa, 73317080e1, cec01395c5, 689f6f77f0, e6135c2768, 33dfd3529b), allocSpan (a762221bea), incremental growth (f18109d7e3), zeroing (a120cc8b36, 4208dbef16), sparse bitmap and inUse ranges (acf3ff2e8a, 9d78e75a0a, 1b1fbb3192, 1475b97090, e7f9e17b79), counting scavenged bits in allocation (e1ddf0507c), memstat atomics (ae4534e659), packaging (7f574e476a), walks (814c5058bb). Left open: address-space-specific work (AIX 5042317d69, a3a630b0d2, darwin/arm64 198f0452b0).
  • Scavenger: returning memory to the OS — Done: page-allocator scavenger, goal in terms of heap_inuse, self-paced, scavtrace (73317080e1, 9b30811280, 21445b091e, 08a72c851c, 8ac98e7b3f, 71154e061f, 2491c5fd241.15, eb96f8a574, e5ce13c178, 62e4156552, 2c87be436b, 8a5af7910a, 4e3d58009a, d183253572, dcd3b2c173, f511467532) [user-visible: GODEBUG=scavtrace]. Left open: rescans previously-scavenged memory each cycle (fixed 1.15).
  • Heap address space: contiguous arena to sparse arenas — Done: platform address-space definitions (198f0452b0, 5042317d69, a3a630b0d2, 947f8504d9, 763d3ac75c, 61ef6a39dd, 8054b13536, ffb5646fe0). Left open: nothing noted.
  • Memory statistics and accounting — Done: atomic heap memstat updates (ae4534e659), useless heap_objects accounting removed (814c5058bb). Left open: nothing noted.

Other changes

  • Misc internal — wasm DataView reuse (07f0460737), tracing deadlock (f266cce676), Plan 9 sysReserve (8054b13536), findObject bad-pointer checks (80315322f3, 813d8e8862, 66f78e9d88), full span init in alloc (a9b37ae026), gcSweepBuf.block guarantee (a5a6f61043), math/bits copies in runtime (11da2b227a), page-size limits (ffb5646fe0), make searchAddr refer to inUse memory (e7f9e17b79), off-by-one in ranges (1475b97090).
