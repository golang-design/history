Go 1.24

Part II · master c622f5c341..9da530f11a · 718 in-scope commits

Swiss-table maps. Spinbit mutex. HashTrieMap-backed sync.Map. weak and AddCleanup. synctest experiment. Generic type aliases. prove’s limit table. mallocgc specialization. vDSO getrandom. Closure-favoring inliner.

Each area lists the stage every thread reached in this release (with what was left open afterwards), then changes that are not part of a thread. Thread names link to the full thread on its topic page.

Memory management

From Runtime: memory allocator and garbage collector (Go 1.18–1.28)

  • Heap bitmap rewrite and allocation headers — Done: GC programs removed from types (45869f5931) and stack objects (5a0f2a7a7c). Small-object bitmap writes were sped up: skipping span.heapBits (−8%, 56fb8350c8) and pre-writing the single possible 8-byte pattern (−6%, 721c04ae4e). Left open: nothing noted.
  • mallocgc decomposition and size-specialized malloc — Done: micro-optimizations (31437f25f2, 6686edc0e7, d8997c8c1f, 8df6413e11, e750a0cdb3, 60ee99cf5d), path split (8730fcf885; −11.6% geomean), and specialized heapSetType (a1c4fb4361; −20.6% geomean). ASAN poisoning was fixed after the split (fb2a7f8ce1, 4bf98186b5). Left open: “We can probably also do more with the size class lookups” (8730fcf885). The split dropped the fresh-span zeroing skip for large pointerful objects (fixed in 1.25, df9888ea4e1.25).
  • Finalizers, runtime.AddCleanup and the cleanup queue — Done: user-visible AddCleanup (0531768b30) and Stop (6a2fb15475). Fixes: the stop search could loop or corrupt non-cleanup specials (7f049eac1b); the closure was kept alive while the special became visible (d69e6f63c3); the arg == ptr check (9d21ef3bd4). SetFinalizer validates arguments before the GC-mode check (252e9def65). Docs (8c3e391573) and race-detector tips in zombie reports (09f9b5e361). Left open: SetFinalizer is to be deprecated (0531768b30).
  • Weak pointers and the unique package — Done: user-visible the public weak package with Strong renamed to Value (a65f1a467f) and docs (c46ba1f9ef, adfd81d8cd, 07398d2e57, 87dbfb9fa7, 772f024c61). Correctness: shading on conversion (79fd633632), blocking during mark termination (80d306da50, test 3bd08b9792), keeping the handle alive while the special is published (88cfad0c89), uintptr special offsets for interior weak pointers >64 KiB (d87878c62b), and a zero Pointer.Value returning nil (d62154db83). unique: stored keys are the clone, not the input (21ac23a96f); zero-size types (2927aa10ab); TypeFor (755c18ecdf); tests and docs (23c9efa244, 1596a6c8ec, b7e4d2067c, a785d11ac4). HashTrieMap moved to internal/sync with a usable zero value (4804d0daca, e8c5e6d635). Left open: the special offset could later be packed with the kind to recover memory (d87878c62b).
  • Mark worker scheduling and GC work queues — Done: futile worker acquisition avoided (e50913cefc). Left open: nothing noted.
  • Allocation publication, zeroing and preemptibility — Done: a publication barrier for delayed-zeroed noscan large objects, for user code on weak memory (acd072a078). Left open: nothing noted.
  • Address-space layout, tagged pointers and the mem.go layer — Done: iOS address-bit docs (cdca671855). Left open: nothing noted.
  • Linear-memory heaps (Wasm and sbrk platforms) — Done: Wasm uses unused linear memory at the break, including linker-reserved initial memory (4510586f93); aligned reservations round the break instead of over-reserving, and sbrk systems drop arena hints (22664f33b7). Left open: nothing noted.

Scheduler and concurrency

From Runtime: scheduler, timers, channels, locks and synchronization (Go 1.18–1.28)

  • Timer rewrite: per-P timer heap, timer.lock, and GC-able synchronous timer channels — Done: Stop/Reset racing with a running timer now returns true when the run is cancelled (2ebaff4890); isSending bit cleared before locking the channel (ce60f70374), not used for tickers (48849e0866), then turned into an atomic.Int32 counter so more than 8 concurrent firings can be tracked (6a49f81edc; timer struct grows 96→104 bytes within its size class); avoid panic reading an expired synctest timer channel (4ce116a884). Left open: nothing noted.
  • Runtime mutex: tri-state futex/sema locks → “spinbit” mutex — Done: groundwork: futex OSes can use the sema-based mutex via new spinbitmutex GOEXPERIMENT value, off by default (18c2461af3); then the spinbit algorithm itself, gated by that experiment and enabled by default where Xchg8 exists (fd050b3c6d); control-flow cleanup (adc9c45587, -2.9% MutexCapture geomean). Left open: platforms needing emulated Xchg8 still on the old tri-state code; two implementations to maintain.
  • testing/synctest bubbles — Done: internal synctest.Run/Wait with fake clock hooks in chan, coro, mgc, lockrank (d90ce588ea); user-visible experimental testing/synctest under GOEXPERIMENT=synctest (76e4efdc77); deadlock avoidance when copying stacks (1d28fa8c43); bubble membership propagated through syscall/js callbacks (a8eddaf758); Run return happens-after goroutine exits (3924fe92b61.25, 1.25). Left open: experiment only.
  • Coroutines (iter.Pull runtime support) — Done: goroutine profile invariants upheld in coroswitch (2a98a1849f). Left open: nothing noted.
  • Asynchronous preemption: extended register state — Done: VZEROUPPER dropped from darwin/amd64 asyncPreempt (fe87b586c0). Left open: nothing noted.
  • sync package API evolution — Done: sync.Mutex implementation moved to internal/sync so sync can later depend on internal/concurrent (frame skip for mutex profiling adjusted) (6c66005285); explicit noCopy fields (53b2b64b64); HashTrieMap added to Map tests/benchmarks (50f1888814); RWMutex upgrade/downgrade doc (bc0406333f). Left open: Map not yet replaced by HashTrieMap in this log.
  • sync/atomic and runtime atomics — Done: intrinsics marked noescape (e30ce3c498); loong64 acquire loads (geomean -74%/-45%) (3214129a83); arm native And8/Or8 (c5d424bfca). Left open: nothing noted.
  • Netpoller — Done: kqueue EVFILT_USER one-shot events save about one syscall per wakeup (21b5f2637a). Left open: nothing noted.

Other changes

  • cgo callbacks and Goexit on C threads internal — stack bounds saved/restored at cgocallback so repeated C->Go calls on the main thread avoid slow pthread_getattr_np (76a8409eb8); syscallbp as unsafe.Pointer (54fe0fd43f); clearer Goexit-on-C-thread error (3da4281df1, 820329508a).
  • Weak-to-strong blocking at mark termination internal — 80d306da50.
  • Misc internal — injectglist holds trace acquire across casgstatus (f025d19e7b); synctest idle defer (953a1bec48); js notes without maps (2caf638e2f); wasmimport pointer types (73ac82f990); getcallerpc noescape (a02516a379); linkname for wireguard (846fc6345d); arm And8/Or8 fix (5dbb0a5c6b); fips service indicator (f0b51a2099).

Data structures and type metadata

From Runtime: maps, built-in data structures, hashing, randomness and type metadata (Go 1.18–1.28)

  • Swiss-table maps (GOEXPERIMENT=swissmap → only implementation) — Done: user-visible GOEXPERIMENT=swissmap created with forked files (057b703407), ABI/compiler integration split into old and swiss variants (4f7dc282c4), fast variants initially disabled (1985c0ccf9), initial table without incremental growth (0733682e5f), wired into the runtime enough to pass all.bash (c39bc22c14; missing: race/concurrent-write detection, stack-allocated maps, fast variants, indirect key/elem, all added later in the cycle: 2220fd3636, b5fec2cf54, f782e16162). Extendible hashing (d94b7a1876), small-map direct group (77e3d8cf13), mapaccess1/mapassign moved from runtime to internal/runtime/maps (0564fa6820), capacity hints (3b424cfa9d), shift/modulo optimisations (bb46b754be, cd54b9bae9), deleted-slot reuse (efa43c57b1), big-endian support (3352db152b), no re-copy of indirect key/elem on grow (d4b0bd28ee), single hash on delete (4c8ab993cd), int-key small-map lookups (d51f92e737), simpler small-group lookup that stops once no filled slots remain (a867e5e5a6, -11% geomean), constant elem offset for int64/string keys (c14fc500c7, 253a9933d1), one fewer hot-path load (63f762bcde), hash a copy of the key rather than the key (d13e6d0b08). Iteration: Iter stores the group across Next calls (aefb173b0a, 7b3ac0ca5d) and uses a hybrid single-slot-then-group-match strategy (7c40544441: low-load maps had regressed +60% vs old maps; testing a full group match on every call regressed mostly-full maps, hence the hybrid). Small-map lookups with long string keys do a quick equality prefilter over all slots and only hash if more than one passes (04807d3acf); return after fatal keeps the key in a register in the probe loop (43725ba283). reflect got swiss GroupSize support (02df9bbdbd) and dropped mapiterkey/mapiterelem (7ba074fe43). Compatibility: mapiterinit/mapiternext are linknamed by third parties with the old hiter layout, so new mapIterStart/mapIterNext were introduced for the toolchain and the old names became a compat layer (78e6f2a1c8, 8071f2a169). Left open: default on but GOEXPERIMENT still exists; nothing in the 1.24 messages noting concrete unfinished items besides the “single table without directory” idea in 77e3d8cf13 (“left for later”).
  • Compiler-generated equality/hash functions and type descriptor emission (reflectdata) — Done: GC programs removed from type descriptors; the runtime builds the pointer bitmap on demand (45869f5931, -110 net lines: reflectdata, linker data.go/decodesym.go, abi.Type, reflect.type); abi.NoEscape treated as cheap call (b6efbd4efc). Left open: MaxPtrmaskBytes stayed at 2048 (revisited in 1.27).
  • internal/abi type layout unification and type metadata (rtype → abi.Type) — Done: GC programs removed from abi.Type handling (45869f5931). Left open: nothing noted.
  • reflect implementation: performance, allocation and escape behaviour — Done: structType.Field avoids allocation (493517bb5c), swiss GroupSize (02df9bbdbd), MapIter without mapiterkey/elem (7ba074fe43), MapOf flag tests (7dac9898c3). Left open: nothing noted.
  • memmove / memclr / memequal / internal/bytealg assembly optimisation — Done: loong64 memmove/memclr/Compare (547baafa37, 501b389efc, 50e536daa1), arm64 Equal (b915399e7e), arm64 memclr block alignment (b4712ab055), riscv64 IndexByte (606a0bd9c8). Left open: nothing noted.
  • Concurrent hash-trie map (internal/sync.HashTrieMap) — Done: all above. Left open: reverted optimisation of CompareAndSwap/Swap.
  • Classic map maintenance and maps package helpers (pre-swiss) — Done: 1b4cf43e42, 1f8fa4941f, linkname allowlists for map functions (8391579ece). Left open: swiss replacement.

Other changes

Middle end and SSA optimizer
