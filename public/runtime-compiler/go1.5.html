Go 1.5

Part II · commits first contained in tag go1.5 ^go1.4 (tagged 2015-08-19) · 1617 in-scope commits

The toolchain is Go: compilers, linker and assemblers translated (cmd/compile, cmd/link, cmd/asm, cmd/internal/obj), C compilers deleted. Concurrent GC with pacer, assists and stack barriers. GOMAXPROCS defaults to NumCPU. Execution tracer. Build modes c-archive, c-shared and shared. ppc64 and arm64 ports. Frame-pointer experiment.

Each area lists the stage every thread reached in this release (with what was left open afterwards), then changes that are not part of a thread. Thread names link to the full thread on its topic page.
