Go 1.2

Part II · commits first contained in tag go1.2 ^go1.1 (tagged 2013-11-29) · 531 in-scope commits

Cooperative preemption via stackguard0. Funcdata/pcdata and pointer maps; precise stack scanning built but shipped opt-in (precisestack). New in-memory symbol table and pclntab. Three-index slices. Per-P allocator caches and persistentalloc.

Each area lists the stage every thread reached in this release (with what was left open afterwards), then changes that are not part of a thread. Thread names link to the full thread on its topic page.

Memory management

From Memory management: GC and allocator (Go 1.0–1.17)

Allocator refinement for per-P caches (whole-span transfer, inlined malloc fast path), persistentalloc, lazy page table and flexible 64-bit mapping; precise stack scan tried and reverted.

  • Stop-the-world mark-sweep, then the parallel collector — Done: the collector runs on g0 instead of a goroutine stack (71f061043d, de316388a7), and may not be triggered from g0 (dfdd1ba028); GC and the finalizer goroutine are synchronised for the preemptive scheduler (72c4ee1a9d); setGCPercent race fixed (94dc963b55). Left open: nothing noted beyond stack precision.
  • Stack scanning: conservative, precise by frames, stack barriers, hybrid barrier, async safe points — Done: stack-by-frames scanning enabled (0e6007e4f9) and then disabled (c3dadca977). Left open: cost of gentraceback and incomplete precision.
  • Precise heap scanning: type information, the heap bitmap and GC programs — Done: type info for interface values (21ea5103a4), array/slice fix (c6293d2106), cnewarray (5782f4117d). Left open: nothing noted.
  • Size classes, tiny allocator and mcache/mcentral — Done: whole-span transfers, inlined classification and MCache_Alloc, simplified MCache (23ad563119, 5a89b35bca, 5166013f75, c4cfef075e, c075d82cca), persistentalloc for small metadata (47e0a3d7b1, 86da989ee5). Left open: nothing noted.
  • Scavenger: returning memory to the OS — Done: Windows SysUnused (4e76abbc60), scavenger details printed on FreeOSMemory (9f46efce52). Left open: nothing noted.
  • Heap address space: contiguous arena to sparse arenas — Done: lazy page table (671814b904, 8bbb08533d, ccd1d07cc4), flexible 64-bit mapping (a8ad859c30), persistentalloc use (99922aba8b). Left open: nothing noted.
  • Finalizers and span specials — Done: GC and finalizer goroutine synchronised (72c4ee1a9d), SetFinalizer(func(interface{})) (6350e45892), no finalizers on g0 (6401e0f83f), frame in runfinq hidden (eb04df75cd). Left open: nothing noted.
  • Runtime allocators for runtime metadata and the port to Go — Done: persistentalloc, FixAlloc use (47e0a3d7b1, 86da989ee5, 99922aba8b, 4f514e8691), mheap hidden from GC (2a6520c2d3), all sys memory accounted (a33ef8d11b, see stats). Left open: nothing noted.
  • Memory statistics and accounting — Done: user-visible GCSys, OtherSys, all sys memory accounted (a33ef8d11b), cheaper stats (5d637b83a9, c075d82cca). Left open: nothing noted.

Other changes

  • Leaks and dead code internal — one-time Linux memory leak (fd41926347), dead type-metadata allocation removed (0a904a3f2e), markfreed messages (139cc96a57).
  • Heap-sizing fixes internal — MSpan.limit for large spans (d6f89d735e), coalescing bug in heap (9ba551bb87), 64-bit atomic cas64 (fb63e4fefb, f70a19f085), GC-time scan fixes (2f5825d427, 50ba6e13b4, c51152f438, df3e6ce4b1), and not marking OS memory as executable on Windows (28f74608b5, 3d513faa6f).
  • Rename FlagNoPointers to FlagNoScan internal — Renamed the malloc flag because it better describes objects that have pointers but that the GC should not scan. (d0dd420a24)

Scheduler and concurrency

From Scheduler and concurrency runtime (Go 1.0–1.17)

Cooperative preemption of long-running goroutines (10ms), GODEBUG/schedtrace, stack and thread limits, Windows and Solaris pollers; threads: preemption, netpoll, diagnostics.

  • The G-M-P scheduler: from global-lock M:N to per-P run queues, spinning Ms and work stealing — Done: fairness 4bb491b12e (global runqueue no longer starved when goroutines keep re-readying each other); CPU underutilization fixes 15a1c3d1e4/32fef9908a (newproc/ready were “deliberately sloppy” about waking Ms); starttheworld race dbcfed93e7; sysmon no longer parks while goroutines run 156e8b306d/658d19a53f; singleproc removed d5ab784611; stack size limit 757e0de89f and thread count limit 665feeedcb; LockOSThread fix 4961483e7d; windows priority boost disabled a574822f80. Left open: timers/locks still via notes.
  • Preemption: cooperative stack-check preemption (1.2) to signal-based asynchronous preemption (1.14) — Done: user-visible preempt function (354ec51666, not yet used), preemption for GC (1e112cd59f), preempt goroutines running more than 10ms (bc31bcccd3), enabled by default a20784bdaf after temporary disable/re-enable (08e064135d, b913cf84dc, 1da96a3039), debugging knob removed 10ebb84d48, old gcwaiting checks removed f195ae94ca; notetsleepg and notetsleep returning false on timeout for preemptive sysmon e97d677b4e, e932c2035f; sysmon polls network if idle >10ms 6857264457. Left open: loops without function calls cannot be preempted.
  • Network poller: from the netFD select loop to the runtime-integrated epoll/kqueue/IOCP poller — Done: Windows poller moved into the runtime 6ea7bf253c with GetQueuedCompletionStatusEx batching 65834685d3; Solaris (event ports, level-triggered) 50df1364831.3; netpoll refactors 8486d96a27, 2ea859a7791.3 (level-triggered IO); FreeBSD/ARM e82614e5be; deadlines for already-issued IO aaab946943; netFD fdMutex 23e15f7253; fewer allocations per IO 04b1cfa946; netpollready called once per event 82ef961af5.
  • Timers: timerproc goroutine → per-bucket heaps → timers on Ps — Done: 4-ary heap fcf6a7e5ce, monotonic clock on linux/386, amd64 86c976ffd01.3, tsleep overflow 3548ab5ebb, fewer notewakeups in timerproc d1b66439f9, network timers crash 9707f269c1.
  • Channels and select — Done: close/send race detection in select 62747bde6c; chan blocking profile incl. select and close c92287686d; closechan stack split 10d1e55103.
  • Semaphores, runtime locks and Notes — Done: notetsleepg e97d677b4e; notetsleep timeout result e932c2035f.
  • sync.Mutex, RWMutex, WaitGroup, Cond, Once — Done: Cond without allocation 5a20b4a6a9; WaitGroup race fixes 0f4897ae1a, 07cb48c31f.
  • sync.Map, atomic.Value and sync/atomic — Done: user-visible Swap functions 0e15b03f93, 883530c019, 66c58cea67.
  • Goroutine and M lifecycle: caches, ids, LockOSThread, Goexit, cgo extra Ms, deadlock detection — Done: deadlock in cgo programs 34c67eb24e; Goexit during init 14062efb16; false deadlock 1da1030b5d; traceback of running goroutines via freezetheworld 01f1e3da48.
  • Stop-the-world, safe points and GC–scheduler interaction — Done: preempt goroutines for GC 1e112cd59f; stoptheworld race dbcfed93e7.
  • Scheduler diagnostics: schedtrace, GODEBUG, execution tracer, block/mutex profiles — Done: user-visible GODEBUG 4b536a550f, schedtrace/scheddetail 4f2e382c9f, creator in running traceback c33d490020, block profile for channels c92287686d.
  • GOMAXPROCS, thread and resource limits — Done: user-visible stack and thread limits 757e0de89f, 665feeedcb.

Other changes

  • netFD fdMutex and net allocations internal — 23e15f7253, 04b1cfa946.
  • Misc runtime internal — GODEBUG-gated e69012ce2a, goroutine stack accounting 187b9c695f, fix traceback with cgo 326ae8d14e, 33bd9694cd.
  • Small scheduler/poller fixes after the preemptive scheduler internal — fee1d1cda0 (G status after syscall), b65271d008, ae5991695c, 91d35ad1b8 (Windows netpoll blocked-call deadlock), a0935cc979, 8f746af65d, 5290e55164 (persistentalloc in netpoll), 38abb09a2e, cc0a005c9d, 0286b4738e, e33e476e07 (disable CPU profiling around fork), d91219e458, 3d6bce411c, 1308194204.
  • Plumbing internal — 081129e286, b36f2db12a, ab1270bcfc, 3453a2204b, f8a850b250, c7d5c438a2, a05237f20a, 8b789e1738, ce9ddd0eee, 6d68fc8eea, 16d6b6c771, 551ada4742, 828a4b9376, c4579635cf.

Data structures and type metadata

From Runtime data structures and type metadata (Go 1.0–1.17)

Hash lookup shortcuts, hashmap internals get typed GC info instead of bespoke GC code, itabs from persistentalloc, faster x86 memmove, Slice3, and ARM softfloat/preemption fixes.

  • Hash map core: from the first hashmap.c to the 8-entry bucket design — Done: Hmap cut to 48 bytes (4042b77776), hash-lookup shortcuts for same-length strings (a696ae56db), type information recorded for the internal structures and all hashtable-specific GC code removed (fb376021be, preceded by 0df438c683 telling GC not to scan them), fix for iterator/growth/NaN-key interaction (869368a528), shorter lookup stack frames (a3f842a4c1). Left open: accessors still took key/value by value via C varargs.
  • Map growth, iteration order, overflow buckets and GC interaction — Done: typed GC data replaces bespoke GC code (fb376021be), iterator/NaN/growth bug (869368a528). Left open: nothing noted.
  • Map fast paths and compiler/runtime specialization — Done: lookups optimized with same-length string checks (a696ae56db, BenchmarkSameLengthMap 43→4 ns).
  • Interface values, itabs and type assertions — Done: itabs from persistentalloc (b36f2db12a), SetFinalizer accepts any compatible f (5822e7848a), wrappers for blank-interface methods skipped (f316a7ea87).
  • reflect redesign: from string parsing to Type/Value structs — Done: user-visible Value.Slice3, SetCap (4d8aefde47); Interface of non-addressable no longer allocates (94179d61ab, InterfaceBig 90→14 ns), Convert indir-bit fix (0e73497a4b), DeepEqual visit key (f7b5a01999, 780f5b714d), call arguments exposed to GC (0ab8f2d287).
  • memmove, memclr, duff routines and pointer-write atomicity — Done: fast x86 memmove (6021449236), ARM memmove parameter corruption fix (f8fd77baa9).
  • internal/bytealg and string/byte comparison primitives — Done: Compare for bytes/strings (b3946dc119).
  • Strings: concatenation, conversion and printing helpers — Done: correct types for maxstring/concatstring (98a80b95b4, 249f807c39).
  • Soft-float, 64-bit division and complex arithmetic helpers — Done: no preemption in softfloat, argument/frame records (e03dd07981, 8166b2da19, 6a13897bc6, cba880e04a), 386 uint64 division (70138a2108), timediv avoiding _vasop (c7d5c438a2).

Other changes

  • Hashtable/reflect constants and docs internal — BUCKETSIZE/MAXKEYSIZE/MAXVALSIZE unexported from reflect (da50221e8e), FieldByName shortcoming documented (7fb3d8e45e).
  • ARM/Plan 9 build fixes in data files internal — 64db2ec915, 14e3540430, 184b02ea9f, 33bd9694cd, 9ddfb64365 (argument size recorded in assembly functions), 249f807c39, 98a80b95b4, f4f2cf16b0.
