Go 1.16

Part II · commits first contained in tag go1.16 ^go1.15 (tagged 2021-02-16) · 862 in-scope commits

runtime/metrics. Late call expansion. pclntab restructured and sym.Symbol deleted. //go:embed. 387 removed in favour of softfloat. GOOS=ios. MADV_DONTNEED by default again. Early devirtualization. Frame pointers no longer an experiment.

Each area lists the stage every thread reached in this release (with what was left open afterwards), then changes that are not part of a thread. Thread names link to the full thread on its topic page.
