Go 1.10

Part II · commits first contained in tag go1.10 ^go1.9 (tagged 2018-02-15) · 793 in-scope commits

Buffered write barrier. Soft and hard heap goals. Per-P timer buckets. Threads can exit and LockOSThread nests. DWARF location lists. AVX/AVX2 in the assembler. Open-addressed itab table. Linker code-health refactor and content-based build IDs.

Each area lists the stage every thread reached in this release (with what was left open afterwards), then changes that are not part of a thread. Thread names link to the full thread on its topic page.

Memory management

From Memory management: GC and allocator (Go 1.0–1.17)

Soft/hard heap goals and 5% assist headroom, buffered write barrier, worker scheduling cleanup.

  • Decentralized GC state machine and mark termination simplification — Done: user-visible runtime.GC() forces a cycle even with GOGC=off (0744c21b98); SetGCPercent(-1) waits for concurrent GC (64b68bedc5); STW duration measured more accurately (250a9610a4), gctrace CPU fix (89b7a08aea). Left open: nothing noted.
  • GC pacer: trigger controller, assists and background utilisation — Done: soft and hard heap limits, 5% assist headroom, utilisation separation (03eb9483e3, af192a3e22, 27923482fa, 315c28b788, 28e1a8e47a, b783930e63, e09dbaa1de). Left open: nothing noted.
  • Hybrid write barrier and buffered write barrier — Done: buffered barrier (e9079a69f3), bulk barriers buffered (877387e38a), typedslicecopy rewrite (6a5f1e58ed), reset on all flush paths (043f112e52), heapBits.bits nosplit (3675bff55d). Left open: fast path implemented only for amd64 per the commit message.
  • Allocating from mark bits: allocBits, freeindex and ctz — Done: nextFreeFast inlinable (101fbc2c82), array-of-1 allocation special case (29e9b89b9a). Left open: nothing noted.

Other changes

  • Malloc comment improvements internal — Added a max waste column to the size class table comment and improved nextSample comments. (a6ae01a64a, 8e11cb3f3b)

Scheduler and concurrency

From Scheduler and concurrency runtime (Go 1.0–1.17)

Per-P timer buckets, nested LockOSThread, no GOMAXPROCS limit, xorshift fastrand; threads: timers, lifecycle, random.

  • The G-M-P scheduler: from global-lock M:N to per-P run queues, spinning Ms and work stealing — Done: user-visible GOMAXPROCS limit eliminated ee55000f6c; no sleeping before stealing unless the victim P is running 868c8b374d; fractional GC workers on all Ps e09dbaa1de; sched.mnext int64 6c7bea6309; allp race in findrunnable 7c2cf4e779.
  • Network poller: from the netFD select loop to the runtime-integrated epoll/kqueue/IOCP poller — Done: only call netpoll if netpollinited 86cd9c1176; errno positive in netpollopen 4a0dcc2de1.
  • Timers: timerproc goroutine → per-bucket heaps → timers on Ps — Done: per-P timer buckets 76f4fd8a52; sift functions optimized 6a7c63a08a; early return from deltimer a72e26f246; monotonic zero on low-resolution clocks 986582126a.
  • Channels and select — Done: selectdone moved into g 32b94f13cf; makechan memory checks 455775dae6.
  • sync.Map, atomic.Value and sync/atomic — Done: Value without noCopy 0c0c3c186b.
  • Goroutine and M lifecycle: caches, ids, LockOSThread, Goexit, cgo extra Ms, deadlock detection — Done: nested LockOSThread c85b12b579, no thread creation from locked threads 2595fe7fb6, terminating locked threads 4f34a52913, lockedg/lockedm as guintptr 165c15afa3, lockOSThread not for every cgo call 332719f7ce.
  • Stop-the-world, safe points and GC–scheduler interaction — Done: assist credit flush on goroutine exit f10d99f51d; accurate STW duration 250a9610a4.
  • Fast random numbers for the scheduler — Done: xorshift64+ e7e4a4ffa3; sema fix 9d9722a2e1.

  • Map fast paths and compiler/runtime specialization — Done: the series listed above (dad5d76e8f, 61043d4671, 29e6bdc69c, 0c7fd56951, ec0e2edd3b, 8585f9fdb1, 25bbb695c8, 2a56b023af, dc10aeeff8, aca92f352d, dabc361847). Left open: benchmarking was “impeded by #21546” per several messages.
  • Hash functions and algorithm tables: memhash, AES hash, fallback hash — Done: specialized memhash32/64 (2a56b023af, 176cd48e57), CPU-feature detection refactor for 386/amd64 (5a6c5809901.9 in 1.9).
  • Runtime type descriptors: layout, shrinking and name encoding — Done: struct field reflect info fixes (d349fa25df), Noalg types out of typelinks (a4c009f5ae), dtypesym returns *obj.LSym (d36cc9baf3).
  • Interface values, itabs and type assertions — Done: compile-time function pointers (89d74f5416), hash table (3d1699ea78, 98d0634b7a, 04d6f982ae, fcf445dce2, d30f99647a).
  • reflect.Call, MakeFunc, method values and argument-frame GC precision — Done: interface→interface conversion in Call (eafa29bdce), zero-sized return value pointer (0a48185b43).
  • reflect performance, caches and API additions — Done: Copy from string (245e386e4c), safety audit of unsafe additions (8bb51a73e9), method indexing for non-ASCII (6f1724ff41, 77b4beba2f).
  • memmove, memclr, duff routines and pointer-write atomicity — Done: arm64 SIMD IndexByte/memclr (d259815ccb).
  • internal/bytealg and string/byte comparison primitives — Done: arm64 IndexByte/memclr SIMD (d259815ccb).
  • Slices and append: growslice, makeslice and string/slice conversions — Done: simplified capacity check, overflow, infinite loop fixes (365594ad59, 371a5b494a, f3e0d14313).
