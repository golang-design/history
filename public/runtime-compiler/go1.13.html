Go 1.13

Part II · commits first contained in tag go1.13 ^go1.12 (tagged 2019-09-03) · 567 in-scope commits

New escape analysis on by default. Stack-allocated defer records. Background scavenger. Go 2 number literals and signed shift counts. Spec-compliant package init order. sync.Pool victim cache. internal/reflectlite.

Each area lists the stage every thread reached in this release (with what was left open afterwards), then changes that are not part of a thread. Thread names link to the full thread on its topic page.

Memory management

From Memory management: GC and allocator (Go 1.0–1.17)

Background scavenger, first-fit address-ordered allocation, huge-page-aware scavenging, effective GOGC.

  • GC pacer: trigger controller, assists and background utilisation — Done: effective GOGC and no GOGC in minimum sweep distance (5c22842cf2, 4a7d5aa30b, 7da03b9fbb). Left open: nothing noted.
  • Stack scanning: conservative, precise by frames, stack barriers, hybrid barrier, async safe points — Done: gp._panic, defer closure scanned (af8f4062c2, 4f4c2a79d4) with clobberfree; stack freeing separated from shrinking (68d89bb8e0). Left open: nothing noted.
  • Size classes, tiny allocator and mcache/mcentral — Done: division → multiply/shift (6ca51f7897). Left open: nothing noted.
  • Span lifecycle in mheap: free lists, treaps, first-fit and the page reclaimer — Done: first-fit, unified treap, in-place split, filtered iteration, treap iterator conversions (40036a99a0, 8c05d67661, 9baa4301cf, 5c15ed64de, fa8470a8cd, 7bb8fc1033, 7b33b6274f, a62b5723be, f4a5ae5594, ff70494b75). Left open: the heap lock held for all span operations, and a tree allocator that would not scale: replaced in 1.14.
  • Scavenger: returning memory to the OS — Done: background scavenger and removal of periodic scavenger (fe67ea32bf, eaa1c87b00), huge-page-aware (a62b5723be, 31c4e09915, 8c3040d768, f4a5ae5594, ff70494b75, 4e7bef84c1 newly mapped memory is marked scavenged because on most OSs untouched pages are not resident). Left open: scavenging pacing relied on estimates; 1.14 made it self-paced.
  • Heap address space: contiguous arena to sparse arenas — Done: wasm memory handling (460f9c6068 optimise memory allocation on wasm, c2d9eea1f1 no arena hints on wasm), sbrk alignment (5b15510d96), first persistentalloc chunk aligned (c5babcc485). Left open: nothing noted.
  • Allocation-site profiling and GC debugging modes — Done: clobberfree (af8f4062c2). Left open: nothing noted.

Other changes

  • Misc internal — latent TODOs resolved (9c86eae384), debugging prints removed (12e63226b9), scavenge-in-coalescing guard (2ab6d0172e), scavengeLargest merge (23d4c6cdd6), heap lock stack growth invariant (7ed7669c0d).

Scheduler and concurrency

From Scheduler and concurrency runtime (Go 1.0–1.17)

Pool victim cache and lock-free queues, inlinable sync fast paths, preemption on many short syscalls, poller error reporting; threads: Pool, Mutex, preemption.

  • The G-M-P scheduler: from global-lock M:N to per-P run queues, spinning Ms and work stealing — Done: look for an idle P when switching to a GC worker or trace reader e56c73f17b; initP/destroyP split out of procresize 9d088fbfda; switch to P0 before destroying current P 4598c23c6c; acquirem/releasem used more widely ea9859f858; P statuses documented b0c6165605.
  • Preemption: cooperative stack-check preemption (1.2) to signal-based asynchronous preemption (1.14) — Done: user-visible a goroutine that runs many short syscalls is now preempted (the 10ms rule did not cover them) 4166ff42c0.
  • Network poller: from the netFD select loop to the runtime-integrated epoll/kqueue/IOCP poller — Done: user-visible event-scanning errors reported on read events a5fdd58c84, narrowed to critical errors only 451a2eb0ab, disabled on Solaris e0181ff52a.
  • Semaphores, runtime locks and Notes — Done: AIX noteclear 1956b28ae3; notetsleep sanity check ac40a7fb9e; js/wasm lock implementation cd03664f82.
  • sync.Mutex, RWMutex, WaitGroup, Cond, Once — Done: inlinable fast paths (above).
  • sync.Pool — Done: lock-free queues 2b60567002, 57bb7be4b1, d5fd2dd6a1, victim cache 2dcbf8b369.
  • Fast random numbers for the scheduler — Done: randomized package initialization order in race mode 8515d9cf65.

Other changes

  • Misc internal — eaa1c87b00 (periodic scavenging removed), d016330241 (debugCall whitelisting), 98c5a56f01, 7a43f8a5fb, 480df2c2b4, db42bb3b70, 0188cb0e8a, f448c212a1, ad832284c7, b51c157025, bc593eac2d, 91c385b393, 29f14f058d.
