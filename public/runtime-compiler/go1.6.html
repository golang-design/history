Go 1.6

Part II · commits first contained in tag go1.6 ^go1.5 (tagged 2016-02-17) · 719 in-scope commits

GC pause work: root jobs in workers, decentralised state machine. Hand-written parser replaces yacc. cgo pointer checks (cgocheck). mips64. PIE and shared libraries on more architectures. MSan. Concurrent-map-misuse detection.

Each area lists the stage every thread reached in this release (with what was left open afterwards), then changes that are not part of a thread. Thread names link to the full thread on its topic page.

Memory management

From Memory management: GC and allocator (Go 1.0–1.17)

Pause work: root jobs in workers, STW loops removed, decentralised state machine, background GC goroutine removed.

  • Concurrent sweep and proportional sweep — Done: remove the in-use page loop and the sweep-wait loop from the STW phases (dac220b0a9, 9a31d38f65); sweep termination decentralised (9630c47e8c, a51905fa04); credit fixes (7407d8e582, 6383fb6152, 87d939dee8, c1cbe5b577, ff5c945382); simplified mSpan_Sweep (70462f90ec). Left open: nothing noted.
  • Concurrent mark: write barriers and the dev.garbage collector — Done: concurrent scan and mark-2 root rescans performed by GC workers (82d14d77da, fbf273250f); span roots, data/BSS root marking partitioned into 256K chunks (d3df04cd8c); finalizer-bearing objects scanned concurrently (608c1b0d56); STW loops over all spans removed (dac220b0a9, 9a31d38f65); work buffers 256 B → larger (1870572180), two cached workbufs per gcWork to cut flapping (b6c0934a9b), work.partial removed (feb92a8e8c), eager balancing of buffers (9439fa1078); GODEBUG=cgocheck=2 uses the barrier to detect Go pointers written to non-Go memory (be1ef46775) user-visible. Left open: stack re-scan in mark termination still O(# stacks); fixed in 1.7 (2a889b9d931.7) and removed in 1.8 (hybrid barrier).
  • Decentralized GC state machine and mark termination simplification — Done: decentralised start, sweep termination, mark done (f54bcedce1, 9630c47e8c, a51905fa04, 12e23f05ff, c99d7f7f85, 171204b561, 3842596284), GC coordinator goroutine removed (d5ba582166, bbf2da00fc), gcMode type (fbd2660af3), GCstw phase removed (a42f668654), state lifted into work (1959621584, b0d5e5c500, 3cd56b4dca). Left open: mark 2 and gchelper still present.
  • GC pacer: trigger controller, assists and background utilisation — Done: direct per-G assist balance, assists before allocating, preemptible, park/ready (89c341c5e9, 65aa2da617, 456528304d, 15aa6bbd5a), heap distance (9e77c89868), proportional sweep fixes (7407d8e582, 6383fb6152, 87d939dee8). Left open: nothing noted.
  • Finalizers and span specials — Done: concurrent scan of finalizer objects (608c1b0d56), tiny-alloc finalization fix (bf606094ee). Left open: nothing noted.
  • Mark work distribution: parfor, work buffers, gcWork and root jobs — Done: root jobs and buffers (572f08a064, d3df04cd8c, 1870572180, b6c0934a9b, 9439fa1078, feb92a8e8c, 62ba520b23, dcd9e5bc0f), mark workers attached to P after parking (eb3b1830b0). Left open: nothing noted.
  • Allocation-site profiling and GC debugging modes — Done: cgocheck=2 (be1ef46775) user-visible. Left open: nothing noted.

Other changes

  • Closed GC races internal — tiny-allocator clear in mark termination (835c83b40d, 4d39bb6a3a), stat underflow (97dc591534), sleep/wakeup of assists (b05f18e3f7).
  • Diagnostics and API hygiene internal — pointer diagnostics (b7c55ba496, 97b64d88eb, b307910b6e, 14aacc2fd8, 26397f1383), assist/drain consolidation (39ed682206, 9b3cdaf0a3, c18b163c15, 4cca1cc05e, 28f458ce5b, d986bf2741, 1698018955, 4ac4085f8e), stack span freeing outside STW (56ad88b1ff), nowritebarrierrec annotations (ab9d5f38be, 27df2e3f76), stack barrier races (a4a57bb4f9, d446ba99a4), sweep trace (4ad64cadf8, 1e1ea66991), unsafe clean-ups (4c2465d47d, 4562784bae, c279250946, 7df8ba136c, 29330c118d, 4ff231bca1, c17c42e8a5, ee0305e036, 7d1d642956), Plan 9/Windows (31430bda09, 1cb53ce36b).
