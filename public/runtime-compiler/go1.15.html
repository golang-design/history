Go 1.15

Part II · commits first contained in tag go1.15 ^go1.14 (tagged 2020-08-11) · 963 in-scope commits

The new linker: dev.link’s conversion to the loader is complete and the old object format is deleted. Static lock ranking. Lock-free mcentral. Typed aux and the rulegen rewrite. Small-integer interface conversions without allocation. darwin/386 and darwin/arm removed.

Each area lists the stage every thread reached in this release (with what was left open afterwards), then changes that are not part of a thread. Thread names link to the full thread on its topic page.

Memory management

From Memory management: GC and allocator (Go 1.0–1.17)

Lock-free spanSet-based mcentral, offset-address ranges, zombie-slot detection, scavenger watermarks, preemptible dedicated mark workers.

  • Concurrent sweep and proportional sweep — Done: markrootSpans driven by a per-page “has specials” bitmap rather than the sweep buffers (eacdf76b93); small-object sweeping while allocating bounded to 100 spans (08bf64a81e); zombie-slot detection (ea2de3346f); every marked object also marks its span (886caba73c, fixing missed marks from gcmarknewobject/wbBufFlush1). Left open: nothing noted.
  • Decentralized GC state machine and mark termination simplification — Done: dedicated mark workers can be preempted for STW (79b43fa819), clearing the way to allow STW during mark; gcStart preemption window closed (03ba6b070d). Left open: nothing noted.
  • Precise heap scanning: type information, the heap bitmap and GC programs — Done: only scan up to ptrdata, not size (08dd4ad7e3), materializeGCProg rounding fix (ab5a40c5e3). Left open: nothing noted.
  • Size classes, tiny allocator and mcache/mcentral — Done: new mcentral (see span-set item); OnesCount64 for allocated counts (67c2dcbc59). Left open: nothing noted.
  • Span lifecycle in mheap: free lists, treaps, first-fit and the page reclaimer — Done: spanSet and new mcentral (8af8fa9103, 9582b6e8fd, a13691966a, d1798d5aa0, 39380e8e01, eacdf76b93), leftover fields removed (9933f665551.16 in 1.16). Left open: nothing noted.
  • The bitmap page allocator — Done: correctness hardening: allocToCache updates searchAddr validly (287d1ec96c), linearAlloc and grow overflow (2e455ec2eb, 14ae846f54), offset addresses (d69509ff99, ea5f9b666c, 796786cd0c, dfd613e0e4), pageAlloc.find validation (b56791cdea), a barrier after span allocation (c53b2bdb35), DWARF arenaBaseOffset for viewcore (12c01f7698). Left open: nothing noted.
  • Scavenger: returning memory to the OS — Done: watermark-based search (dba1205b2f, 55ec5182d7), defensive pacing (c7915376ce). Left open: nothing noted.
  • Finalizers and span specials — Done: bitmap-based markrootSpans (eacdf76b93). Left open: nothing noted.
  • Allocation-site profiling and GC debugging modes — Done: zombie slot report (ea2de3346f). Left open: nothing noted.

Other changes

Scheduler and concurrency

From Scheduler and concurrency runtime (Go 1.0–1.17)

Static lock ranking, Ticker.Reset, Map.LoadAndDelete, timer stealing and poller-local queueing; threads: lock ranking, timers, Map.

  • The G-M-P scheduler: from global-lock M:N to per-P run queues, spinning Ms and work stealing — Done: goroutines found by the poller go on the local run queue 2fbca94db7; newproc1 no longer starts the goroutine b3863fbbc2; wakep condition moved inside 4e00b4c366; runqputbatch holds sched.lock 6b4dcf19fa; startm/checkdead visibility 85afa2eb19.
  • Preemption: cooperative stack-check preemption (1.2) to signal-based asynchronous preemption (1.14) — Done: no preemption signal if one is already pending 0c0e8f224d; preempt-stop cleared in dropm 8de0bb77eb1.14; cleantimers returns early if the G is being preempted 5d70cb0667; e8be350d78 blocks preemption while a timer is timerModifying.
  • Network poller: from the netFD select loop to the runtime-integrated epoll/kqueue/IOCP poller — Done: converge duplicate netpollBreak calls (89% faster) 0cc1290174; Windows always uses GQCSEx e3cf0525b0; AIX break races 78a45d8b45, 45f99d85e0; netpollWakeSig uint32 245409ea86; error code names d98023ebb5; pollDesc/netpollunblock refinements 33357270f1.
  • Timers: timerproc goroutine → per-bucket heaps → timers on Ps — Done: user-visible time.Ticker.Reset 6e5652bebe/402ea9e4f9; timers on running Ps can be stolen 9b90491e4a; racy timer use no longer panics 98858c4380; resetTimer only from Reset 5f3354d1bf; wakeNetPoller avoided in timerModifying 355f53f0a0; timer/event-handler race 0452f9460f.
  • Channels and select — Done: pack sudog struct 94e61ab94d.
  • sync.Map, atomic.Value and sync/atomic — Done: user-visible Map.LoadAndDelete 2e8dbae85c; panic64 removed a4c48d61f5.
  • Runtime lock ranking (static lock order checking) — Done: static lock ranking 0a820007e7, partial-order edges 1067ab0808, 300ff5d8ac, a81bc8e825, 0f8fecaba7, f474e9e549, e05695ed4d, Gscan ordering f9640b88c7, explicit direction 646b4ac065; the experiment itself arrives via 095ba225971.17 (GOEXPERIMENT parsing simplification, 1.17). Left open: not enabled by default and requires the experiment build.
  • Goroutine and M lifecycle: caches, ids, LockOSThread, Goexit, cgo extra Ms, deadlock detection — Done: debug call injection on a new goroutine 3633d2c545.

Other changes

  • Misc internal — 3093959ee1, 85162292af, 588ee7987d, ab5a40c5e3, 01a9cf8487, 11b3730a02, c847589ad0, 9340bd610b.
